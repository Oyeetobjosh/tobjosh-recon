# Custom Network Security Automation Utility
A lightweight but powerful, multi-threaded Python automation script engineered for application asset discovery, response analysis, and workflow efficiency during security research engagements. 

## Features
It's high-Concurrency Execution leverages Python's native asynchronous or multi-threaded structures to process targets quickly.
It's Robust Exception Handling Gracefully handles network timeouts, dropouts, and malformed server headers without panicking.
It's Modular DesignBuilt with clean, reusable functions to allow easy integration into broader penetration testing pipelines.
It's Progress Bar Shows a real time progress bar soo as not to confuse you about lagging or network problems

## 🚀 Installation & Wizard Setup

Follow the steps below to clone the repository and spin up the environment. Choose the track that matches your operating system!

### 📥 Step 1: Clone the Arsenal
Open your terminal (Linux) or Command Prompt/PowerShell (Windows) and pull down the source code:

```bash
git clone [https://github.com/Oyeetobjosh/tobjosh-recon.git](https://github.com/Oyeetobjosh/tobjosh-recon.git)
cd tobjosh-recon
🎛️ Step 2: Initialize the Virtual Environment
Isolating your project dependencies ensures the tool runs perfectly without messing up your global system packages.

🪟 On Windows Track:
PowerShell
# Create the virtual environment configuration
python -m venv venv
# Activate the isolated environment layer
.\venv\Scripts\activate

🐧 On Linux/macOS Track:
Bash
# Create the virtual environment configuration
python3 -m venv venv
# Activate the isolated environment layer
source venv/bin/activate
📦 Step 3: Load the Dependencies
Bash
pip3 install -r requirements.txt
⚡ Step 4: Fire Up the Engine
Bash
python3 tobjosh_engine.py
